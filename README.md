** Contextualização ** 
Uma empresa deseja organizar melhor seus dados de vendas. Atualmente, as informações estão dispostas
em planilias  e não há um sistema centralizado para consultas mais rápidas.A direção decidiu criar um banco de dados 
relacional para armazenar dados de clientes, produtos e pedidos, permitindo análises mais eficientes e reltporios confiáveis.

** Desafio**
Implementar um banco de dados em SQL que atende ás necessidades da empresa. O desafio envolve:
-Modelagem das tabelas necessárioas(Pedidios, Clientes, Pedidos).
-Ciação das tabelas com chaves primárias e estrangeiras.
-Insersão de dados fictícios para simular o funcionamento da loja.
-Consulta SQL que repondam ás seguintes perguntas:
  -Quaisclientes realizaram mais compras?
  -Qual produto mais vendido no último mês?
  -Qual o valor total das vendas por cliente?
  -Listar os pedidos que ultrapassam determinado valor?

  ** Resultados esperados**
  -Um banco de dados funcional criado em SQL que poderá ser utilizado em aplicações reais.
  -Compreender como funcionam as relações entre as tabelas de um banco de dados.
  -Criar um script de insersão, alteração e exclusão de dados.
  -Um conjunto de consultas SQL que repondam ásperguntas propostas.
  -Empregar técnicas de normalização dos dados.
